# Rapido-Ride-Analytics-Dashboard-Power-BI-
Interactive Power BI dashboard analyzing 148K+ ride-hailing bookings for Rapido (bike taxi, auto, cab). Tracks 93K completed bookings, 51.8M revenue, and 2.51M total distance across 6 vehicle types.

Multi-page report: Overview, Vehicle, Revenue, Rider, Location — covering booking status, revenue trend, rider segments (first-time/return/regular), payment methods, top pickup/drop zones, and peak demand time slots.

Built with Power BI Desktop, DAX measures, and custom data modeling
